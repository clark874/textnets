# 环境牌边权对照：`term_weight` vs `count`

日期：2026-08-14  
语料：Notebook 实际读取的 `/Users/moongoat/Downloads/按列合并的文档数据.csv`（11 个主题文档）  
分词：环境牌 Notebook 的 jieba + 自定义词典 + 词性白名单 + 哈工大停用词  
种子：`tn.params["seed"] = 42`  
代码：`scripts/compare_edge_weights.py`

两种建图共用同一张已经算过 tf-idf 的 TidyText，只改 `Textnet(..., edge_weight=...)`。

## 结论

**未加权拓扑完全相同，加权解释并不相同。**

在这份 11 文档语料上，2024 年把边权从官方 `term_weight` 改成出现次数，会改变：

- 边权排序（`top_n_terms=5` 时 Spearman ρ = −0.34）
- 词项加权中心度的前十名（10 个里只重叠 2 个）
- 二分网络的 Leiden 社区数（48 vs 7）
- 词项投影的强度排序（ρ = −0.40）
- 全词文档投影的文档强度排序（ρ = 0.13）

因此不能再把两种边权当成同一张网的两种画法。它会改主题词排序，也会改社区形态。  
这仍不是对原论文统计结论的证伪：这里没有对照已发表图表的黄金样本，只证明 **Notebook 当年那条建图路径对边权方案敏感**。

## 语料规模

| 项 | 值 |
|---|---|
| 文档 | 11（成分信息、生态文明、食品安全、评估情况、排放背景、外交关系、信息公开、技术方案、公众舆论、责任义务、多边合作） |
| 分词后词项 | 96 |
| TidyText 行 | 180 |
| 自定义词典 | 9130 |
| 停用词 | 779 |

`食品安全` 同时是文档名和词项名，比较时按 `(type, id)` 对齐，避免索引碰撞。

## 二分网络

| 设置 | 节点 | 边 | 拓扑相同 | 边权 ρ | 社区数 term_weight / count | 词项强度 ρ | 词项 BiRank ρ | 词项 HITS ρ | 前十词重叠 |
|---|---:|---:|---|---:|---|---:|---:|---:|---:|
| `top_n_terms=5`（Notebook 主网） | 53 | 55 | 是 | −0.34 | 48 / 7 | 0.24 | 0.86 | −0.19 | 2 |
| 全词 | 107 | 180 | 是 | 0.21 | 102 / 4 | 0.63 | 0.86 | 0.01 | 4 |

未加权度数完全一致（词项 ρ = 1）。`top5` 下每个文档恰好保留 5 个词，文档度数是常数，Spearman 无定义。

`top5` 的边权呈 **负相关**，说明官方 tf-idf 抬高的是稀有而专指的词，计数边权抬高的是反复出现的通词。

### `top5` 词项强度前十

| 官方 `term_weight` | 2024 `count` |
|---|---|
| 信息 | 海洋环境 |
| 国际原子能机构 | 食品安全 |
| 监测 | 高度 |
| 评估 | 负责的态度 |
| 福岛核电站 | 福岛 |
| 含氚废水 | 国际社会 |
| 海洋环境 | 核泄漏 |
| 沟通交流 | 周边国家 |
| 韩方 | 人类健康 |
| 食品安全 | 产生 |

官方方案更接近机构名和专有处置对象；计数方案更接近高频套话和通名。

社区数 48 vs 7 不能单独当成“一种对、一种错”。官方二分 Leiden（CPM）在很小的 tf-idf 权重上容易碎成近单点社区；整数计数则并成大社区。这是 **算法 × 边权** 的交互，不是单纯的实现 bug。但它足以说明：若论文图用了 `show_clusters=True`，两种边权画出来的簇不会是同一回事。

## 投影网络

| 设置 | 拓扑相同 | 边权 ρ | 强度 ρ | 中介中心度 ρ | 社区一致率 |
|---|---|---:|---:|---:|---:|
| top5 文档投影 | 是 | −0.07 | 0.63 | 1.00 | 0.89 |
| top5 词项投影 | 是 | −0.39 | −0.40 | 1.00 | 0.93 |
| 全词文档投影 | 是 | 0.62 | 0.13 | 0.65 | 0.65 |
| 全词词项投影 | 是 | 0.35 | 0.17 | 0.80 | 0.82 |

Notebook 里文档投影来自 `textnet_chinese_all`（全词）。这份对照里，全词文档强度排序几乎对不上（ρ = 0.13），社区数是 2 对 3。  
词项投影若走 `top5` 主网，前排词项会整体翻面。

## 对三个项目的含义

| 项目 | 含义 |
|---|---|
| 环境牌 | 活跃复用。主图若按 2024 安装包默认计数边权生成，词项排序和聚类不能直接当成官方 0.10.x 的结果 |

| 福岛 | 历史废弃，不进入此次对照 |
